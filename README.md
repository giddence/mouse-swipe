# MouseSwipe

一个约 20 KB 的 Windows 托盘小工具：把任意鼠标的标准侧键改成

- **轻点侧键** → 打开 / 关闭任务视图（Win+Tab）
- **按住侧键左右滑动** → 切换到左边 / 右边的虚拟桌面

不需要 Logi Options+，不需要安装运行时（Windows 10/11 自带的 .NET Framework 4.8 即可），
对罗技、微软、雷蛇、双飞燕等所有发送标准侧键事件（XBUTTON1 / XBUTTON2）的鼠标都有效。

## 快速开始

1. 运行 `build.bat` 生成 `MouseSwipe.exe`（使用 Windows 自带的 .NET Framework 编译器，无需安装开发环境）。
2. 双击 `MouseSwipe.exe`。
3. 托盘出现蓝色双箭头图标即表示已启动。
4. 直接用鼠标侧键操作即可。

如果侧键原本是“后退 / 前进”，本工具会把这两个事件拦下来，浏览器等程序不会再执行后退/前进。

## 托盘菜单

右键托盘图标：

| 菜单 | 说明 |
| --- | --- |
| 手势侧键 | 默认“侧键 1（后退）”；也可选侧键 2，或用“按下侧键来识别”后按一下想用的侧键 |
| 滑动识别距离 | 一次连续滑动至少移动多少像素才被识别，默认 80（最高 300）；识别后滑得再远也只切换一个桌面 |
| 反向 | 右滑改为切换到左侧桌面 |
| 开机自动启动 | 写入当前用户启动项（HKCU，不需要管理员） |
| 使用说明 | 查看简要帮助 |
| 退出 | 卸载钩子并退出 |

## 操作细节

- **轻点**：按下再松开、期间没有形成一次滑动，松开时发送 Win+Tab。
  任务视图已经打开时再轻点一次，会发送 Win+Tab 把它关掉。
- **滑动**：按住侧键，水平移动超过“滑动识别距离”后切换一个桌面。
  **一次连续滑动只切换一个桌面，滑得再远也不会连续闪切。**
  要再切换，停下约 0.15 秒后再滑，或者反向滑动；因此按住不松开也可以左右交替、连续切换多个桌面。
- 垂直移动、斜向移动、轻微手抖都不会触发滑动。
- 滑动切换使用的是 Windows 原生快捷键 `Ctrl+Win+←/→`，**不会弹出任务视图**，
  只有轻点才会打开任务视图。这样响应最快，也不会和任务视图的状态互相干扰。
- 滑动方向按鼠标移动方向：向右移动 = 右边的桌面。
- 按住侧键期间，指针会锁定在按下时的位置：左右滑动时指针不会跟着跑，切换后仍停在原位
  （和 Logi Options+ 的手势键效果一致）。松开后指针恢复正常移动。
  已处理高 DPI 缩放（125% / 150% / 200%），坐标按物理像素处理。

## 鼠标兼容性 / 为什么有时要改驱动里的按键

本工具识别的是 Windows **标准侧键事件（XBUTTON1 / XBUTTON2）**，这也是所有鼠标“后退 / 前进”键的通用事件。

- **绝大多数鼠标不需要做任何设置**：出厂时侧键默认就发送标准 XBUTTON，插上即用。
- 只有厂商驱动把侧键改成了宏、快捷键或厂商私有手势事件时，才需要在该驱动里恢复成 **“后退 (Back)”/“前进 (Forward)”**。
  否则 Windows 收到的不是标准侧键，本工具（以及任何通用侧键工具）都收不到。
- **换一个普通鼠标通常什么都不用改**。如果新鼠标的驱动也改过键，同样把侧键恢复成“后退 / 前进”即可。
- 这不是本工具的硬性要求，而是“通用侧键”这个接口本身的边界：厂商私有按钮必须先在驱动里改成标准侧键，Windows 才能看到。

### 罗技

1. 在 **Logi Options+** 里把要用的侧键设为 **“后退 (Back)”** 或 **“前进 (Forward)”**。
2. 不要设为“无操作”、宏、快捷键或 Smart Action。
3. 不需要卸载 Options+，但同一个侧键不要再绑定其它动作。
4. 如果是 MX Master 的拇指“手势按钮”，也请先在 Options+ 里把它映射成“后退”或“前进”；
   某些型号的专用手势键默认只发厂商私有 HID++ 事件，Windows 看不到。
5. 改完后可以试试退出 Options+；如果侧键仍然有效，就可以不常驻 Options+。
   如果退出后侧键失效，说明该按键依赖驱动，需要保留 Options+ 或换一个标准侧键鼠标。

## 已知限制

- 只处理标准侧键 XBUTTON1 / XBUTTON2；厂商私有按钮（不发送标准侧键）无法识别。
- **以管理员身份运行的程序**（例如管理员权限的编辑器、游戏）获得焦点时，
  非管理员进程注入的 Win+Tab / Ctrl+Win+方向键可能被 Windows 拦截。
  如果确实需要，右键 `MouseSwipe.exe` → “以管理员身份运行”。
- UAC 安全桌面、锁屏界面不会触发。
- 使用 Raw Input 独占鼠标的游戏 / 带反作弊的程序可能不受影响，也不建议在竞技游戏里使用。
- 本程序会安装全局低级鼠标钩子，个别安全软件可能提示风险；程序不联网、不收集数据，
  源码就在 `MouseSwipe.cs`，可以自行用 `build.bat` 编译。

## 开机启动 / 卸载

- 开机启动：托盘菜单勾选“开机自动启动”（写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）。
  建议先把整个文件夹放到固定目录（例如 `C:\Tools\MouseSwipe`）再勾选；移动文件夹后重新勾选一次即可更新路径。
- 卸载：先取消勾选“开机自动启动”，托盘菜单“退出”，然后删除本文件夹即可。
- 设置保存在 `HKCU\Software\MouseSwipe`，删除该注册表项即可恢复默认。

## 现成的替代软件

如果不想用这个自写工具，也有通用的鼠标手势软件，但都需要更多配置或额外运行时：

- **StrokesPlus.net**：免费、通用鼠标手势，可为侧键画手势并绑定快捷键；功能多，体积和配置也比本工具大。
- **MouseGestureL.ahk**：基于 AutoHotkey 的手势脚本，支持侧键；需要安装 AutoHotkey。
- **X-Mouse Button Control**：非常轻量，可把侧键映射成 Win+Tab，但不原生支持“按住 + 方向滑动”的手势，只能做单击映射。
- **PowerToys**：目前没有鼠标侧键手势功能。
